# 💪 Perfect Health Fitness and Gym

Welcome to the **Perfect Health Fitness and Gym** website repository! This project is a modern, responsive, and interactive landing page designed for a premium fitness center. It showcases a holistic approach to health, combining workout plans, nutrition advice (featuring traditional Nepali diets), and community support.

## 🌟 Features

This website is packed with dynamic features and a polished user interface:

### 🎨 Design & UI

- **Responsive Layout**: Fully optimized for desktops, tablets, and mobile devices.
- **Glassmorphism & Gradients**: Modern aesthetic with sleek visuals.
- **Parallax Effects**: Engaging background movement on scroll.
- **Smooth Scrolling**: Seamless navigation between sections.
- **Custom Animations**:
  - **Scroll Reveal**: Elements fade and slide in as you scroll.
  - **Smart Typewriter**: Dynamic text typing effects for headings.
  - **Ripple Buttons**: Material Design-inspired click effects.

### 🛠 Interactive Tools & Widgets

- **BMI Calculator**: A popup widget that calculates Body Mass Index (BMI), estimates body fat percentage, and provides personalized diet and workout tips based on the result.
- **Review System**: A unique "Bicep Rating" system where users can leave reviews. High ratings (4+ biceps) trigger a celebratory confetti animation! 🎊
- **Dynamic Counters**: Animated number counters for member statistics.

### 🥗 Content Sections

- **Hero**: Engaging landing area with call-to-action buttons.
- **About**: Information about trainers, facilities, and philosophy.
- **Services**: Details on personal training, group classes, and more.
- **Diet Plans**: A special section highlighting healthy **Nepali Diet** options like Dal Bhat, Dhindo, and Gundruk. 🇳🇵
- **Benefits**: The physical and mental advantages of joining.
- **Contact**: A functional-looking contact form with validation and success messages.

## 🚀 Technologies Used

- **HTML5**: Semantic structure and accessibility.
- **CSS3**: Advanced styling, Flexbox, Grid, keyframe animations, and media queries.
- **JavaScript (Vanilla)**: All interactive logic, DOM manipulation, and event handling without external libraries.
- **Google Fonts**: Uses 'Poppins' for modern typography.
- **FontAwesome / Icons**: Uses emoji-based icons for a lightweight footprint.

## 📸 Highlights

- **Nepali Diet Integration**: Promotes local, nutritious superfoods.
- **Interactive Feedback**: The review widget allows users to post mock reviews instantly without a backend.
- **Mobile-First Approach**: The navigation menu transforms into a hamburger menu on smaller screens.
